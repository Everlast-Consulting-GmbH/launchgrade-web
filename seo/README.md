# SEO Content Workflow

This folder keeps the 80/20 SEO strategy for a Launchgrade project. It is intentionally lightweight: no API keys, no paid-tool dependency, no rank tracker.

## Process

1. Define the business goal and target audience.
2. Map one primary keyword and one search intent to each important indexable page.
3. Create a short content brief before writing or expanding a page.
4. Build the page, keeping internal links and CTA aligned with intent.
5. Run the normal Launchgrade setup/audit workflow for technical SEO.
6. After launch, connect Google Search Console, submit the sitemap, and refresh content based on real queries.

## Useful Free Inputs

- Google SERP review
- Google Autocomplete and related searches
- Google Trends
- Google Search Console after launch
- SISTRIX Free Keyword Tool
- Ahrefs Free Keyword Generator
- Ahrefs Webmaster Tools for verified own domains

Treat free-tool data as directional. Do not invent search volume or keyword difficulty when no source provides it.
